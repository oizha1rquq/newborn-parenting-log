# 【健康科普】特应性皮炎知多少——天津医科大学第二医院皮肤科医生为您讲解特应性皮炎

> 更新时间：2026-09-16 (UTC+8)

**特应性皮炎知多少**

特应性皮炎大多发生于过敏性体质的患者，当出现病情后往往给患者的生活工作带来较大的麻烦，无论是正常的休息还是工作，都会不分昼夜的折磨患者。很多人以为这只是简单的皮炎便不放在心上，任由其肆意发展，最终给病人的身体带来诸多其他问题。下面一起来认识下特应性皮炎，不再让其为所欲为。

**1**

什么是特应性皮炎（AD）?                          它和湿疹是一回事吗？

特应性皮炎又叫特应性湿疹，俗称“痒醒症”，呈慢性、复发性、炎症性皮肤表现。常伴有皮肤屏障功能障碍；本人或家族中容易罹患哮喘、过敏性鼻炎、过敏性结膜炎、荨麻疹等；血清中IgE水平升高和外周血嗜酸性粒细胞增多。

我们老百姓所说的“湿疹”，其中大部分是特应性皮炎。

**2**

如何判断自己是湿疹还是特应性皮炎（AD）？

**“中国标准”教你轻松诊断特应性皮炎**

1. 对称性湿疹超过6个月

2. 个人或亲属曾经或现在患有过敏性鼻炎、哮喘或过敏性结膜炎等特应性疾病

3. 血清总IgE升高或外周血嗜酸性粒细胞升高或者一种以上特异性IgE阳性？

**判断标准：**

1. 当您满足第一条基础上同时满足第2条或第3条，就基本伤可以自我诊断为特应性皮炎（AD）了。

2. 如果您不满足第2条，又没有做过任何化验检验，那么建议您及时来正规医院皮肤科就诊，进一步检查明确诊断。

**3**

特应性皮炎（AD）会传染或遗传给子女吗？

特应性皮炎（AD）不是传染病，不会传染给他人或者被他人传染，但有一定的遗传倾向。

**4**

日常有哪些注意事项？

1. 衣：衣物宽松舒适，建议纯棉、透气的衣物。尤其是贴身衣物应避免羊毛、化纤、金属等容易致敏的材质。

2. 食：食物过敏在儿童特应性皮炎中可见，故避免食用致敏食物，但无需过分忌口。

3. 住：生活环境保持适宜的环境温度，室内勤通风，避免接触尘螨、动物皮毛、花粉等过敏原。还要避免使用地毯、羽绒被等可能有潜在过敏原的生活用品。

4. 行：制定适合自己的运动计划、坚持每天锻炼身体的同时，应劲量避免过热和出汗过多的激烈运动。外出应防止过度日光暴晒，避免高致敏性场所，如装修市场、动物园、恰逢花季的植物园。如果必须前往上述场所，请佩戴口罩。

5. 洗：洗是特应性皮炎患者需要特别注意的一个问题。避免过度洗浴，洗澡次数不宜过多。每日一次或隔日一次即可；淋浴10分钟或更短的时间。不要使用过热的水烫洗。

6. 避免搔抓：搔抓是不良刺激，可导致皮损加重甚至继发感染，非但不能缓解症状，还会加重病情，因此要避免搔抓。

此外，应放松心情，避免焦虑。及配合医生，提高自身依从性。
