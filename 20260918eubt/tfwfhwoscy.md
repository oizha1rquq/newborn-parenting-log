# 婴儿补充维生素d3

> 更新时间：2026-09-18 (UTC+8)

婴儿需要补充维生素d3吗

婴儿需要补充维生素d3。

维生素是维持人体正常生理功能必需的一类物质。一般不能在体内合成，或合成量太少，必须由食物供给；虽然身体的需要量很小，但在调节物质代谢过程中有十分重要的作用。而维生素D就是维生素的一种，因它可以溶解在脂肪和有机溶剂中，不能溶解在水中，属于脂溶性维生素。

维生素D根据结构形式的不同，主要有维生素D2和维生素d3，维生素D2主要由植物性食物提供，维生素d3主要由动物性食物提供，以及7-脱氢胆固醇经紫外线作用转化生成。可以维持血钙水平；促使骨、软骨及牙齿矿化；促进小肠钙的吸收；促进肾脏对钙、磷的重吸收。

由于维生素D几乎不能通过乳腺，母乳中维生素D含量很低。又由于膳食中富含维生素D的食物很少，建议乳母与婴幼儿必要时可补充维生素D制剂，以改善母子双方维生素D的营养状况和促进膳食钙的吸收，维持母乳中钙水平的恒定，以利于婴儿的生长发育，及帮助弥补孕期(和哺乳期)母体骨骼钙的丢失。

由此可见，维生素d3对婴儿的重要性。家长们在日常生活中要切实留意宝宝维生素d3是否充足。
 
婴儿补充维生素d3怎么补

大多人都会认为婴儿补充维生素d3就是靠保健品补充的，但其实不止这个方法，生活中还有其他更简单便捷的方法，一起来学习一下吧。

1、适当晒太阳 这是最有效、方便和经济的方法。经常让宝宝在户外活动。春秋天，你可直接让宝宝在太阳下，夏天在树阴下，使宝宝的皮肤经常接触紫外线。紫外线照射，可促进皮肤内贮存的7-脱氢胆固醇，经光化学作用转化为维生素D3。太阳光照射，可使皮肤贮存维生素D3备用，不会使维生素D过量。

2、口服维生素D 食物中除海鱼的肝脏含一定量维生素D外，乳类(包括人乳和牛奶)、蛋黄和肉类中含量均很少，谷物、蔬菜和水果几乎没有，婴幼儿每天从天然食物中摄取的维生素D不能满足他们发育的需要。正常孩子不分年龄，每人每天需要补充维生素D400单位，而早产儿、先天贮存不足者或生长过速婴儿需要量增加。因此，口服维生素D量应适当增加。维生素D的制剂很多，家长可以自行选用，每天定量给孩子服用。一般从出生后半个月到1个月开始服用，一直服到2岁半或3岁。

特别需要注意的是：

1、如果宝宝服用维生素D强化的配方奶，根据奶量计算维生素D的用量，不足部分加以补充，避免因维生素D过量而中毒。

2. 宝宝服用维生素D过多是会中毒的。400单位是每天的维持量，不是治疗量。

3. 如果发现你的宝宝有佝偻病，必须在医生的指导下，给予相应的治疗。

由于婴儿的体质较为脆弱，因此建议要服用保健品补充维生素d3的话还是需要咨询专业医师的意见和建议，以保证发挥保健品的最大功效。
 
婴儿补充维生素d3补多少

一般婴儿出生一段时间之后就需要补充维生素d3，但是鉴于宝宝的特殊性，补充的量还是需要有所掌控的。婴儿补充维生素d3要补多少呢？一起来了解一下吧。

维生素d3是天然维生素D的一种，是脂溶性维生素，它有一个重要的功能，就是提高人体对钙和磷的吸收。简单地说，维生素d3是帮助钙吸收的。我们都知道补钙的重要性，但是如果缺乏维生素d3，钙就不能够被很好的吸收。所以补充维生素d3比补钙本身更重要。只有摄入足够量的维生素d3，才能保证孩子健康成长。

新生儿满月后，应当到户外适当晒太阳，并且给予服用维生素D制剂，每日400-800单位，并适当服用钙片；也可以肌肉注射维生素D注射液，每次15万单位，可以供给4个月的需要，每隔4-6个月再注射1次。口服与注射均有防治软骨病的作用。两岁以后的小儿已能吃多种食物，而且户外活动较多，一般不易缺乏维生素D，可以停用维生素D制剂。

维生素d3应该适量地补充即可，如果不太清楚量是多少合适，就应该咨询专业医师，以免宝宝服用过量出现中毒现象！
 
婴儿补充维生素d3的作用

维生素D是人体重要的物质，有利于维持人体机能正常运作。婴儿补充维生素d3有什么作用呢？下面一起来看看吧！

一般情况下，维生素D缺乏可引起肠道钙和磷的吸收减少，肾脏对钙和磷的重吸收减少，造成骨骼和牙齿矿化异常、骨骼畸形等。如：佝偻病、骨质软化症、手足搐搦症、骨质疏松症等。同样，维生素D如摄入过量也会中毒，常表现为食欲不振、恶心呕吐，引起高钙血症和高钙尿症，导致钙在软组织沉积及不可逆转的肾脏、心肌损害。

动物性食物是天然维生素D的主要来源，如含脂肪高的海鱼和鱼卵。瘦肉、坚果、人乳、牛乳中维生素D含量较低，蔬菜、谷物及其制品、水果中含少量或几乎不含维生素D。

维生素D每日的需要量是400个国际单位，这个需要量比较少，在夏季、春季经常在户外活动，充分享受阳光的照射，一般来讲，这个剂量维生素D会得到满足。有的孩子冬天接受的户外活动很少，缺少活动可能会出现维生素D的缺乏，维生素D缺乏是导致孩子缺钙主要因素。 维生素D的缺乏，一旦诊断得到了明确，应该在医生的指导下进行维生素D的补充。但是如果用的过多，或者是不适合就可能出现中毒，因此大剂量的维生素D治疗应该在医生的指导下来做。

家长们要切记切忌擅自决定用量，以免对宝宝造成严重的伤害！
