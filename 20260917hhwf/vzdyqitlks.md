# 惧怕做试管婴儿?千万别信了那些谣言

带你一步步走进真相

**谣言****：****试管婴儿可以帮助女性晚点怀孕**

**真 相**

这是一个错误的观念。如今不少女性因为事业或者其他原因而错过了受孕的“黄金”年龄，认为反正有试管婴儿技术，晚点儿生育宝宝也没有多大关系。

试管婴儿是可以助孕，但是女性年龄超过35岁后，由于卵巢功能、卵子质量明显下降，导致生育能力急速衰退，即便采用试管婴儿，也无法获得与年龄女性相同的理想治疗效果或助孕结局。

**谣言****：****试管婴儿是在试管内长大的**

**真相**

不少人以为试管婴儿就是在试管里培育孩子，等长大了再放入子宫。事实上，试管婴儿是将卵子与精子一起放入培养皿中，在体外完成受精并发育形成胚胎，再将胚胎转移到子宫腔内，使之在子宫内着床、继续生长，从而逐步发育为胎儿。简单来说，试管婴儿中体外的培养皿代替了输卵管的功能。

**谣言****：****试管婴儿宝宝的身体和智力发育不如自然妊娠宝宝**

**真相**

试管婴儿与正常受孕的婴儿一样，都是通过父亲和母亲的生殖细胞结合而形成的胚胎，继承了父母的遗传物质，因此，身体发育和智力等级均与正常生育的婴儿没有什么差别。

**谣言****：****试管婴儿代数随便选择**

**真相**

部分患者以为只要肯花钱，试管想做几代就几代，其实不然，医生会严格把控夫妻双方的适应症，不会让患者随意选用。

一代试管（IVF-ET，体外受精-胚胎移植技术）适用于输卵管堵塞、子宫内膜异位症等因素引起的不孕；

二代试管婴儿（ICSI，单精子卵胞浆内显微注射）适用于严重的男方因素导致的不孕，如严重的少、弱、畸精症，不可逆的梗阻性无精子症，生精功能障碍，体外受精失败，精子顶体异常；

三代试管婴儿（PGT，胚胎植入前遗传学诊断）适用于：染色体数目、结构异常, 如非整倍体、平衡易位等；单基因遗传病。

**谣言****：****促排卵会导致卵巢早衰**

**真相**

合理合法、适量地使用促排卵药物不会影响卵巢功能，更不会导致卵巢提前衰老。

**谣言****：****促排卵，卵泡越多越好**

**真相**

促排卵过程中，优势卵泡数较多（＞15个）是发生卵巢过度刺激综合征（OHSS）的高危因素之一。OHSS是促排卵治疗引起的严重并发症，临床表现为腹痛、腹胀、少尿、体重增加，严重时出现呼吸困难、严重的消化道症状等伴有肝肾功能损害及血栓形成，甚至威胁生命。

**谣言****：****取卵手术很痛很伤身**

**真相**

可以选择“无痛取卵”，在术前进行静脉全麻，患者可以在“睡眠中”完成取卵；如果卵巢位置好或卵泡数量少，可以不需要全麻，减少麻醉的副作用。

术后的不适感对于大部分患者来说，类似于轻至中度的痛经，是在可以承受的范围内的；少数患者疼痛比较强烈或因对镇痛药物敏感而出现恶心或呕吐，需要卧床休息至无不良症状后方可离开医院。

**谣言****：****试管婴儿移植后每天都要卧床**

**真相**

为了“安全起见”，许多患者在胚胎移植术后日夜卧床休养，但有临床研究表明：胚胎移植术后，患者立即行走对治疗结局是没有影响的；另外，胚胎移植术后，任何时长的卧床均无益于妊娠结局，反而卧床时间过长，将不利于提高妊娠成功率。
